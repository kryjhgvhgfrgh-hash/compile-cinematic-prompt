# 工具盒界面

## 首轮方向卡

保持界面短而直观。不要在卡片前写长篇分析。

```markdown
## 🎬 电影提示词工具盒

**模式**：简单确认　｜　快捷切换：`直接编译` · `精细模式` · `三个方向`

**场景锁定**：恰好两名女性 / 雨天车站 / 分别 / 无其他人物

### A｜静谧疏离（推荐）

- 情绪：克制、未说出口的告别
- 空间：大面积负空间、左右分离
- 关系：保持距离、互不接触
- 光线：阴天柔光、少量暖色车厢光
- 色彩：低饱和冷蓝灰、局部琥珀色
- 质感：固定镜头、细腻 35mm 胶片颗粒

### B｜紧张决裂

- 情绪：压迫、关系即将断裂
- 空间：前景遮挡、压缩构图
- 关系：一人移动、一人停留
- 光线：高反差侧逆光
- 色彩：冷青与暗红冲突
- 质感：轻微手持、潮湿硬质反光

### C｜温暖回忆

- 情绪：温柔、记忆正在褪色
- 空间：柔和远景、薄雾分层
- 关系：短暂回望、视觉呼应
- 光线：暖金逆光、柔和光晕
- 色彩：褪色米黄、淡青绿
- 质感：低反差胶片、浅景深

回复 `A`、`A+C`、`A 但更暖`，或说 `你决定`。
```

## 镜头控制台

仅在精细模式中显示。最多列出四项，每项只给一个推荐值和两个替代值。

```markdown
## 🎥 镜头控制台

| 控制项 | 推荐 | 可替换 |
|---|---|---|
| 景别 | 中远景，人物完整可见 | 大远景 / 中景双人镜头 |
| 机位 | 平视固定侧面 | 低机位 / 轻微手持 |
| 构图 | 左右三分、铁轨引导线 | 中轴对称 / 前景遮挡 |
| 介质 | 低反差 35mm 胶片 | 16mm 粗颗粒 / 干净数字电影 |

回复 `按推荐`，或只说需要修改的项目。
```

## 最终输出

````markdown
## 最终电影感 Prompt

```text
[可直接复制到图片模型的完整提示词]
```

**方向配方**：静谧疏离 / 左右分离 / 阴天柔光 / 冷蓝灰＋局部暖光 / 35mm

**场景锁定**：恰好两人；雨天车站；分别；无额外人物；无文字和水印
````

## 快捷命令

- `直接编译`：跳过方向卡。
- `简单确认`：只选择一次视觉方向。
- `精细模式`：方向卡后再确认镜头控制台。
- `三个方向`：一次输出三套完整 Prompt。
- `更冷 / 更远 / 更压迫 / 更柔和`：只修改对应变量。
- `生成图片`：先锁定 Prompt，再调用图片生成能力。
