# 电影视觉语言库

按用户输入动态组合，不要把本文件当成固定套餐清单。每套方案选择一个主情绪、一种空间语法、一种人物关系、一套光线、一套色彩和一种成像介质。

## 情绪方向

- 静谧疏离：克制、停顿、未说出口、时间被拉长
- 温暖怀旧：柔软、记忆感、稍纵即逝、轻微褪色
- 紧张压迫：不稳定、逼仄、失衡、即将发生
- 清洁诗意：安静、高调、纯净、单一视觉意象
- 哥特忧郁：肃穆、衰败、潮湿、历史阴影
- 青春躁动：自发、混乱、快速、未经修饰
- 史诗孤独：尺度悬殊、寂静、未知、巨大负空间
- 梦境悬疑：日常中的异常、方向不明、柔焦与不协调细节

## 空间与构图

- 大面积负空间：让主体缩小并远离画面中心，表达孤独、停顿或尺度。
- 左右分离：让人物分别占据两侧三分之一，表达关系距离。
- 中央轴线：强调秩序、压迫、仪式感或巨大建筑尺度。
- 框中框：利用门、窗、机库或前景物体包围主体。
- 前景遮挡：制造窥视、悬疑、距离和层次。
- 压缩构图：减少空气和逃逸空间，表达紧张或封闭。
- 对角线与倾斜：表达运动、混乱和失衡。
- 分层纵深：组织前景、中景、远景和空气透视。
- 引导线：利用道路、铁轨、车辙、回廊或光束指向主体。
- 图形对比：用大/小、黑/白、实/空、静/动建立清晰视觉命题。

不要同时宣称“中央对称”和“明显三分法”为主构图。只选择一个主结构，其他结构作为辅助。

## 人物关系与姿态

- 保持距离、互不接触
- 无眼神交流、视线朝向不同方向
- 一人移动、一人停留
- 并排但身体略向外转
- 背对镜头、封闭姿态
- 短暂回望、视觉呼应
- 前后错位、遮挡部分身体
- 身体靠近但情绪疏离
- 小幅动作、手部握紧或垂落
- 快速奔跑、衣料和头发产生方向性运动

将情绪落实为姿态、距离、视线和动作，不只写“忧郁”或“紧张”。

## 景别与机位

- 大远景：强调环境、尺度和负空间。
- 中远景：同时保留人物全身与环境关系。
- 中景双人镜头：强调人物互动和姿态。
- 近景：强调表情、视线和细微动作；不要同时要求宏大环境全貌。
- 平视固定机位：克制、观察感、关系清晰。
- 低机位仰拍：放大尺度、威胁或纪念碑感。
- 高机位俯拍：脆弱、孤立或图形化空间。
- 侧面机位：强调距离、移动方向和剪影。
- 三分之四侧面：兼顾主体外形和空间纵深。
- 手持跟拍：即时、躁动、纪录感。
- 荷兰角：仅用于明确的失衡和不安，不作为默认“电影感”。

焦段只在有控制价值时使用：

- 24–28mm：环境广、透视明显、运动感强。
- 35mm：自然环境人像，兼顾空间与人物。
- 50mm：接近自然观察，关系稳定。
- 85–135mm：压缩空间、隔离人物、柔化背景。

不要同时要求超广角透视和长焦压缩。

## 光线语言

- 阴天漫射光：柔和、低反差、安静、潮湿。
- 柔和逆光：轮廓光、空气感、怀旧和抒情。
- 侧逆光：建立人物边缘、环境层次和戏剧张力。
- 硬质侧光：明确阴影、危险、冲突和材质。
- 顶部体积光：建筑尺度、宗教感、尘埃和神秘。
- 窗口单侧光：封闭室内、明暗对比和方向性。
- 高调白光：纯净、空白、脆弱和诗意。
- 低调照明：深阴影、悬疑、选择性可见。
- 冷环境光＋暖实景光：建立空间层次与情感焦点。
- 极端逆光剪影：失去身份细节、强调动作和图形。

说明光源方向、软硬和作用对象。不要只写“电影灯光”。

## 色彩配方

- 低饱和冷蓝灰＋少量暖琥珀：疏离、雨天、工业空间。
- 褪色米黄＋淡青绿＋深红锚点：怀旧、乡村、列车。
- 炭黑＋深绿＋局部暖金：哥特、历史、潮湿石材。
- 高调乳白＋纯黑＋单一深红：极简、冬季、视觉象征。
- 沙金＋暖棕＋烟灰：荒漠、热浪、机械。
- 深靛蓝＋铜金＋琥珀：宇宙、史诗、发光物质。
- 冷灰＋湿润橄榄绿：海滨、雨后、军事或工业环境。
- 褪色淡紫＋藏蓝＋浅灰：春日青春、柔和记忆。

指定主色、辅色和最多一个强调色。不要罗列过多颜色。

## 空气与材质

- 薄雾：柔化远景、降低反差、增加层次。
- 体积光：需要烟、尘、雾或湿气作为可见介质。
- 雨后倒影：强化地面材质和冷暖光分区。
- 悬浮尘粒：适合顶部或窗口光束。
- 热浪扭曲：适合荒漠和高温机械场景。
- 潮湿水渍、风化石材、粗糙混凝土、磨损金属：提升表面可信度。
- 胶片颗粒：统一画面；不要把“粗颗粒”用于需要极端洁净的高调画面。
- 轻微光晕：适合强逆光和怀旧；避免覆盖全部细节。

## 成像介质

- 35mm 低反差胶片：细腻、自然、怀旧但仍清晰。
- 16mm 胶片：颗粒更明显、画面更亲密和粗粝。
- 消费级 DV：运动拖影、高光溢出、即时和不安。
- 干净数字电影：自然动态范围、精确材质、克制锐度。
- 大画幅数字电影：宽容高光、自然景深层次、精细环境。
- 物理渲染电影 CGI：用于科幻、天体和无法实拍的场景；强调可信材质和光照。

每套方向只选择一种主介质。除非用户明确要求混合媒介，不要同时使用 35mm、DV 和干净数字电影。

## 将片名或导演名拆解

当用户引用影片、导演或摄影师时：

1. 保留用户想表达的情绪和时代。
2. 推断可见特征：构图、动态、光线、色彩、质感。
3. 在最终 Prompt 中优先写这些特征。
4. 只有用户明确要求保留名称时才附带名称；不要让名称替代视觉说明。
