# 提示词质量检查

## 一、场景准确性

- 明确主体身份和准确数量。
- 明确核心动作，避免同一人物同时执行冲突动作。
- 明确关键物件及其位置。
- 保护用户要求的服装、时代、天气和环境。
- 对高风险错误使用“恰好”“仅有”“面部不可见”等保护语句。

## 二、空间可生成性

- 使用左/右、前/后、上/下、靠近/远离等关系。
- 让人物、环境和镜头可以在同一个视角下同时出现。
- 避免要求近景面部特写同时完整展示宏大环境。
- 避免主体既位于中央又明显位于三分线，除非主次关系清楚。

## 三、视觉一致性

检查常见冲突：

| 冲突 | 处理方式 |
|---|---|
| 阴天漫射光＋强烈硬阴影 | 选择一种，或说明云隙直射光来源 |
| 超广角透视＋长焦压缩 | 选择与叙事目标更相关的一种 |
| 高调纯白＋整体低调照明 | 指定局部黑色主体，而非整体低调 |
| 中央对称＋三分法主构图 | 保留一个主构图 |
| 固定观察镜头＋强烈手持 | 选择一个主要运动语言 |
| 35mm 胶片＋消费级 DV | 选择一种主介质 |
| 浅景深＋所有远近元素清晰 | 指定焦点与允许模糊的层次 |

## 四、专业词有效性

保留能够明显改变像素结果的术语：

- 景别和机位
- 透视与焦段
- 构图和主体尺度
- 光源方向、软硬与反差
- 色彩比例和饱和度
- 空气介质和表面材质
- 成像介质及其可见特征

删除只用于炫技、重复或没有视觉作用的器材品牌、宽泛质量词和同义词串。

## 五、情绪可见性

每个抽象情绪至少对应两个可见证据：

- 疏离 → 人物距离＋无眼神交流
- 压迫 → 压缩构图＋前景遮挡
- 怀旧 → 暖逆光＋轻微褪色胶片
- 孤独 → 小主体＋大面积负空间
- 不安 → 倾斜构图＋不稳定运动
- 纯净 → 高调白场＋极少色彩

## 六、负面约束

只排除高概率错误。通常包括：

- 额外人物或物体
- 文字、Logo、水印和边框
- 与目标相邻但错误的风格，如商业广告、动漫或游戏界面
- 身份敏感场景中的错误面部、姿态或数量

避免使用几十项通用负面词；过长的排除清单会稀释主要画面。

## 七、交付门槛

最终 Prompt 应满足：

- 第一遍阅读即可知道画面里有什么、在哪里、正在做什么。
- 能指出一个主构图、一个主光逻辑、一个主色彩系统和一种主介质。
- 所有术语互相支持，不相互抵消。
- 删除任意一句都会损失一个真实的画面控制变量；否则继续精简。
