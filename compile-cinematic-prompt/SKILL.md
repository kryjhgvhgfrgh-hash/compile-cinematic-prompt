# 电影提示词工具盒

把用户的一句简单描述编译成准确、协调、可生成的电影感图片指令。先保护场景事实，再让用户选择可感知的视觉结果，最后在内部翻译为专业镜头语言。

## 工作原则

- 保留用户明确给出的主体、数量、动作、场景、时代和关键物件。
- 区分“不可改变的场景事实”与“可以探索的视觉表达”。
- 优先使用可见、可执行的关系，不堆砌抽象形容词。
- 让每个专业术语控制一个明确变量：机位、透视、构图、光源、色彩、材质或成像介质。
- 每套方向保持内部一致。不要把互相冲突的摄影语言混在一起。
- 默认只编写提示词。仅在用户明确要求“生成图片”时调用图片生成能力。
- 不依赖导演、摄影师、影片或摄影机品牌名称。把名称拆解为可观察的视觉特征。
- 不要求用户理解摄影术语。让用户选择“静谧疏离”“紧张压迫”等结果，再自动完成技术翻译。

## 选择运行模式

识别用户显式指定的模式；未指定时使用“简单确认”。

| 模式 | 行为 |
|---|---|
| `直接编译` | 自动选择推荐方向，立即输出最终提示词 |
| `简单确认` | 默认；展示三张视觉方向卡，用户选定后输出最终提示词 |
| `精细模式` | 展示视觉方向卡，再展示一次镜头控制台，确认后输出 |
| `三个方向` | 直接输出三套彼此明显不同的完整提示词 |

当用户说“你决定”“直接来”“不用问”时，切换为直接编译。不要继续提问。

## 第一步：锁定场景事实

从用户输入中提取并在内部记录：

```text
主体：身份与数量
动作：正在发生什么
关系：人物或物体如何相对排列
环境：地点、关键物件、天气
时间：时代、季节、时段
硬约束：必须保留或禁止出现的内容
画幅：未指定时，电影剧照默认横屏 16:9
```

不要擅自增加新角色、剧情事件、品牌、文字或关键物件。缺少的视觉参数可以推断；会改变故事含义的信息不要猜测。

## 第二步：展示视觉方向卡

在简单确认或精细模式下，基于同一场景生成三套协调且差异明显的方向：

- A：最符合用户原始语义的推荐方向。
- B：在情绪或空间压力上形成明显对比。
- C：在时间感、色彩或成像介质上提供另一种有效解释。

每张卡只显示六个用户可感知的维度：情绪、空间、人物关系、光线、色彩、质感。每项使用短语，不写成长段解释。

严格使用 [references/toolbox-ui.md](references/toolbox-ui.md) 的卡片格式。根据需要从 [references/cinematic-language.md](references/cinematic-language.md) 选择或组合词汇，但不要机械复制固定套餐。

允许用户回复：`A`、`A+C`、`A 但更暖`、`你决定`。混合方向时指定一个主方向，只借用另一个方向的一至两个特征；不要把两套方案平均搅在一起。

## 第三步：可选镜头控制台

仅在精细模式下，在用户选择视觉方向后展示一次镜头控制台。提供一套推荐值和每项最多两个替代值，只确认高影响变量：

- 景别与机位
- 构图与主体尺度
- 光线与时间
- 成像介质

不要询问模型可以安全推断的细节。一次最多要求用户确认三个选择。用户确认或修改后立即编译，不进入第三轮预生成确认。

## 第四步：编译最终提示词

按以下顺序编写自然连贯的成品指令：

1. 资产类型与画幅
2. 主体、数量、服装或外形
3. 动作、姿态、视线和相互关系
4. 环境、关键物件及空间位置
5. 时代、季节、天气和时间
6. 景别、机位、视角和必要的镜头特征
7. 构图、主体尺度、负空间和引导线
8. 主色、辅色、强调色及饱和度关系
9. 主光方向、软硬、反差和空气介质
10. 材质、动态、成像介质和后期特征
11. 可见的情绪结果
12. 数量保护及必要排除项

让最终提示词可直接用于图片模型。默认写成一个紧凑段落；复杂场景可以分成两段。删除重复同义词、不可见信息和没有控制作用的品牌堆砌。

## 第五步：检查质量

在交付前应用 [references/quality-rubric.md](references/quality-rubric.md)：

- 核对主体数量、身份、动作和关键物件。
- 核对所有空间关系是否可同时成立。
- 核对构图、镜头、光线、色彩和介质是否协调。
- 确认抽象情绪已经翻译为可见证据。
- 确认专业术语确实改变画面，而不是装饰性堆词。
- 确认排除项简短且针对高概率错误。

若发现冲突，按以下优先级处理：用户明确事实 > 主体准确性 > 空间关系 > 情绪方向 > 镜头与构图 > 表面质感。

## 输出最终结果

使用 [references/toolbox-ui.md](references/toolbox-ui.md) 的最终输出格式，至少包含：

```text
最终电影感 Prompt
方向配方
场景锁定
```

当用户只需要可复制内容时，仅返回最终 Prompt。用户要求生成图片时，先完成编译，再把最终 Prompt 交给图片生成能力，并保持场景锁定不变。

## 生成后修正

查看成图后，每轮只修改一个主要问题。例如：主体尺度、人物距离、色温、机位、光线或数量错误。重复所有场景不变量，避免其他部分漂移。不要重新开启完整的方向选择，除非用户明确要求换一种方向。

## 内置视觉示例

`assets/examples/` 保存本 Skill 的实际生成示例。仅当用户要求查看示例、比较视觉方向或说明该 Skill 的成图范围时检查或展示这些图片；不要把它们当作默认风格参考，也不要因此覆盖用户当前场景的事实与选择。
